Recipe Tracker Site Plan

Matthew Fry

Purpose

This website allows users to store and organize their favorite recipes in one place. Users can add new recipes, view saved recipes, and filter them based on categories such as meal type or ingredients. The goal is to make it easy for users to manage and access their recipes quickly.

Audience

The intended audience is students and individuals who want a simple way to keep track of recipes. It is especially useful for people who cook regularly and want an organized way to save and find meals without using complex apps.

Dynamic Elements

This site will use JavaScript to allow users to add recipes through a form. Each recipe will be stored as an object inside an array. The recipes will be displayed dynamically on the page using DOM manipulation.

Users will be able to filter recipes by category such as breakfast, lunch, or dinner using buttons. Conditional logic will determine which recipes are displayed based on the selected filter.

Event listeners will be used to handle user interactions such as submitting the form and clicking filter buttons.

Logo

Logo will be a simple "Recipe Tracker" design created using Canva or a similar tool.

Color Scheme

  • Primary Color: #2c3e50
  • Secondary Color: #ecf0f1
  • Accent Color: #e67e22

Typography

  • Headings: Poppins
  • Body Text: Open Sans

Content

Home Page

Welcome to Recipe Tracker

Keep all your favorite recipes in one place. Add new recipes, organize them, and quickly find what you want to cook.

Instructions

Use the form to add a recipe. Select a category and include ingredients. Your recipes will appear below and can be filtered.
