Game Finder Site Plan

Matthew Fry

Purpose

The purpose of this website is to help users discover video games based on their preferences. Users can browse a collection of games, filter them by genre and platform, and sort them by rating. The goal is to provide a simple and interactive way to explore new games.

Audience

The intended audience is students and casual gamers who want a quick and easy way to find video games to play. This site is designed for users who do not want to search through complex apps and prefer a simple, clean interface.

Dynamic Elements

JavaScript is used to dynamically display and update the list of games. The site stores game data in an array of objects. Each game contains properties such as name, genre, platform, rating, and description.

The displayGames function renders the game list onto the page using DOM manipulation. Users can interact with the site through buttons that filter games by genre and platform using array filter methods.

A sorting feature allows users to sort games by rating using an array sort method. Event listeners are used to respond to user clicks and update the displayed content. Conditional logic determines which games are shown based on the selected filters.

A "View Details" button allows users to view additional information about each game, demonstrating further DOM interaction and event handling.

Logo

The logo will be a simple gaming themed icon such as a controller symbol combined with the text "Game Finder". The design will be minimal so that it scales well and can be used as a favicon.

Color Scheme

  • Primary Color: #2c3e50 (dark blue header)
  • Secondary Color: #3498db (buttons and accents)
  • Accent Color: #e67e22 (highlight buttons)
  • Background Color: #f4f4f4 (light gray background)

Typography

  • Headings: Arial, sans-serif
  • Body Text: Arial, sans-serif

Content

Home Page

Welcome to Game Finder. This site helps users discover video games based on genre, platform, and rating. Users can navigate to the browse page to explore available games.

Browse Games Page

This page displays a collection of games. Users can filter by genre and platform, sort by rating, and click "View Details" to learn more about each game.

Wireframes

Mobile View

  • Header with title and navigation
  • Filter buttons stacked vertically
  • Sort button
  • Game cards in a single column

Desktop View

  • Header at top with navigation
  • Filters displayed horizontally
  • Sort button centered
  • Game cards displayed in a multi-column grid layout
